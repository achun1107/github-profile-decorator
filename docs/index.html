为什么用它

装饰任何人的主页，而不只是你自己的。

不用改别人的仓库

传统做法要往 <用户名>/<用户名> 主页 README 里堆徽章。这个扩展在浏览器侧注入，访问谁就装修谁。

可开关、可换主题

12 个模块独立开关，8 套卡片主题，文案、社交链接、技术栈图标都能在弹窗里改，实时生效。

隐私边界清楚

没有后端、没有分析脚本，配置只存在浏览器里，权限仅限 https://github.com/*。详见隐私政策。

30 秒安装

Chrome / Edge 均可，需要开启开发者模式。

git clone https://github.com/achun1107/github-profile-decorator.git
打开 chrome://extensions（Edge 为 edge://extensions）。
开启右上角开发者模式，点加载已解压的扩展程序，选择刚 clone 的目录。
访问 https://github.com/torvalds，页面底部会出现装饰区；点工具栏图标即可配置。

完整步骤、贡献蛇配置与故障排查见 README。

FAQ

更多排查项见 README 的「FAQ / 故障排查」章节。

装饰区没出现？

确认访问的是个人主页（仓库页 / 组织页不注入）、弹窗「启用注入」已开启，然后在扩展页点「重新加载」并刷新页面。GitHub 改版导致识别失效时请带控制台报错提 Issue。

切换账号主页后没更新？

已适配 GitHub Turbo SPA 路由，切换后有约 0.3–0.5 秒延迟属正常。点过「隐藏 ✕」会在当前路径保持隐藏，换路径自动恢复。

贡献蛇位置显示提示文字？

说明目标用户没有配置生成 Action。需在其 <用户名>/<用户名> 仓库放 .github/workflows/snake.yml，做法见 README。

会不会上传我的数据？

扩展无后端、无分析脚本，不向自有服务器发送数据。配置保存在 chrome.storage.sync；若登录 Chrome 账号，Chrome 自身会同步这份配置。详见 PRIVACY.md。

能直接从商店安装吗？

暂未上架。当前分发方式是 clone + 开发者模式加载；上架进度与待补素材见仓库的 STORE_LISTING.md。
